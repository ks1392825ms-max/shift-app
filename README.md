# 家計簿

MacBook と iPhone のブラウザで使う、個人用の家計簿 Web アプリです。
インストールは不要で、外部との通信もしません。

## 使い方

公開後は、Mac でも iPhone でも公開 URL（下の「公開版」を参照）を開きます。
公開前に Mac だけで試すときは、Finder で `index.html` をダブルクリックします。

| 画面 | できること |
|---|---|
| ホーム | その月の収入・支出（固定費／変動費）・残り、累計の残り |
| 入力（右下の［＋］） | 収入・支出の登録 |
| 明細 | その月の記録の一覧。タップで編集・削除 |
| 集計 | カテゴリー別の支出・収入の内訳、直近6か月の推移 |
| 残り | 月ごとの「収入 − 支出」と、その累計。タップでその月のホームへ |
| 設定 | 同期・バックアップ、カテゴリーの追加・編集・並び替え・削除・復活 |

- ホーム・明細・集計の ◀ ▶ で月を切り替えます（選んだ月は3つの画面で共通）
- カテゴリーを削除しても、過去の記録はそのカテゴリー名のまま残ります
- カテゴリーのグループ（収入／固定費／変動費）は、追加したあとは変えられません（過去の集計が変わらないように）

## 計算方法

- この月の残り ＝ その月の収入 − その月の支出
- 累計の残り ＝ 記録を始めた月から、その月までの「残り」の合計

## データの保存について

- データは、**開いたブラウザの中（localStorage）** に保存されます
- Safari と Chrome では、別々のデータになります。いつも同じブラウザで開いてください
- ブラウザの「履歴・Webサイトデータの消去」をすると、データも消えます
- 別の端末やブラウザとデータを合わせるには、下の「同期」を使います

## 同期（Google Drive）とバックアップ

アプリがインターネットに通信することはありません。データを「同期ファイル」（`kakeibo-sync.json`）にまとめ、
自分で Google Drive に保存して、もう一方の端末で読み込みます。

### 決まりは1つ：「使い始める前に読み込む、使い終わったら書き出す」

1. 設定 →「① 同期ファイルを読み込む」→ Google Drive の `kakeibo-sync.json` を選ぶ
2. 入力する
3. 設定 →「② 同期ファイルを書き出す」→ Google Drive の同じ場所に、同じ名前で保存（置き換え）

- 読み込みは上書きではなく**合体**です。両方の端末で入力した記録は両方残ります
- 同じ記録を両方で編集した場合は、**あとから編集したほう**が残ります
- 書き出し忘れがあると、設定画面に「⚠ 書き出していない変更があります」と出ます

### 最初の準備（Mac・Google Drive for desktop）

1. Finder の「Google Drive」→「マイドライブ」に、`家計簿` フォルダを作る
2. ブラウザごとに、保存先を選べるようにしておく
   - **Chrome**：「② 書き出す」を押すと保存先を選ぶ画面が出ます。`マイドライブ/家計簿` を選び、2回目からは同じファイルに上書きします
   - **Safari**：Safari →「設定」→「一般」→「ファイルのダウンロード先」を「**毎回確認**」にすると、保存先に `マイドライブ/家計簿` を選べます。同じ名前のファイルがあるときは「置き換え」を選んでください
     （設定を変えない場合は「ダウンロード」フォルダに保存されるので、Finder で `家計簿` フォルダへ移して、古いファイルと置き換えます）

### 注意

- ファイルの中身は**暗号化されていません**（収入の内訳なども含まれます）
- Google Drive では「マイドライブ」に置き、**共有リンクを作らない**でください

### バックアップ

- 「バックアップを保存」：日付入りのファイル（例：`kakeibo-backup-2026-09-30.json`）を保存します
- 「バックアップから復元」：今のデータを、ファイルの内容で**丸ごと置き換え**ます
- 復元の直前の状態はブラウザ内に1つだけ残り、「復元を取り消す」で戻せます

## 公開版（GitHub Pages）と iPhone での使い方

公開 URL：`https://＜GitHubのユーザー名＞.github.io/kakeibo/`

- GitHub に置くのは**アプリのプログラムだけ**です。家計のデータは GitHub に送られません
- 公開後は、Mac でも iPhone でも**この URL のアプリを使います**
  （`index.html` をダブルクリックして開いたアプリとは、データが別になります）

### iPhone

1. Safari で公開 URL を開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
3. **以後は必ずホーム画面の「家計簿」アイコンから開く**
   （Safari のタブで開いたものとホーム画面のアプリは、データが別になります）

同期ファイルの読み書き：
- 読み込む：設定 →「① 同期ファイルを読み込む」→「ブラウズ」→ Google Drive →「家計簿」→ `kakeibo-sync.json`
  （「ファイル」アプリに Google Drive が出ないときは、「ブラウズ」の「…」→「編集」で Google Drive をオンにする）
- 書き出す：設定 →「② 同期ファイルを書き出す」→「"ファイル"に保存」→ Google Drive →「家計簿」→「保存」
  （同じ名前のファイルがあると聞かれたら「置き換える」）
- 最新のファイルが出ないときは、Google Drive アプリを一度開いてから、もう一度試す

### ファイルを更新するとき

アプリのファイルを変えたら、GitHub のリポジトリに同じ場所・同じ名前でアップロードし直します。
数分で公開 URL に反映されます。

## フォルダ構成

```
kakeibo/
├── index.html          アプリの入口
├── README.md           この説明
├── manifest.json       ホーム画面に追加したときの設定
├── icons/              ホーム画面のアイコン
├── css/
│   └── style.css       見た目
└── js/
    ├── utils.js        共通の便利関数（日付・金額の表示など）
    ├── storage.js      データの保存・読み込み（保存処理はすべてここに集約）
    ├── calc.js         集計の計算（残り・累計・カテゴリー別など）
    ├── charts.js       グラフを描く部品（ドーナツ・棒グラフ）
    ├── app.js          起動と画面の切り替え
    ├── sync/
    │   ├── merge.js    同期ファイルのチェックと、データの合体
    │   └── file.js     ファイルの書き出し・読み込み
    ├── data/
    │   └── defaults.js 初期カテゴリー
    └── screens/
        ├── home.js     ホーム画面
        ├── input.js    入力画面
        ├── list.js     明細一覧画面
        ├── summary.js  集計画面
        ├── balance.js  残り画面
        └── settings.js 設定画面
```
